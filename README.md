# Rajan Pantha — Portfolio

Modern, high-performance portfolio showcasing video editing, UI/UX design, and creative technology projects.

🌐 **Live Website**: [www.rajan23.com.np](https://www.rajan23.com.np)

---

## ⚡ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Routing**: [React Router](https://reactrouter.com/)
- **Linting**: [Oxlint](https://oxc.rs/)
- **Deployment**: GitHub Pages via GitHub Actions

---

## 🛠️ Local Development

### 1. Clone the repository
```bash
git clone https://github.com/rajanpantha123/My-Portfolio.git
cd My-Portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```

---

## 🚀 Deployment

Automated CI/CD deployment via GitHub Actions is configured in `.github/workflows/deploy.yml`. Pushes to `main` branch automatically trigger a production build and deployment to GitHub Pages.
